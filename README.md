# Web services

Projet de web services en JavaScript avec Node.js et Express. Les dépendances incluent Mongoose pour MongoDB, ainsi que bcryptjs et jsonwebtoken.

## Démarrer le serveur

```sh
npm install
npm run dev
```

Le point d’entrée est `src/index.js`. Le port par défaut est **5000** et peut être configuré via la variable d’environnement `SERVER_PORT`. Utilise `npm start` pour lancer le serveur sans nodemon.
